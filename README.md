# MOHAMMED RAYHAN CHAT BOT

Facebook chat bot project branded for **MOHAMMED RAYHAN**.

## Setup

1. Install Node.js.
2. Run `npm install`.
3. Copy `config.example.json` to your local `config.json`.
4. Add your own credentials/appstate locally.
5. Start with `npm start`.

> Never commit passwords, cookies, appstate files, API keys, or other private credentials.
